# งานที่ 1 — โปรแกรม AI ด้วย kNN (Tkinter)

**เวอร์ชันล่าสุด: ใช้ข้อมูลจริงจาก OpenPowerlifting** (ไฟล์ `openpowerlifting.csv` ที่อัปโหลดมา — ผลการแข่งขัน
ยกน้ำหนักจริง 386,414 รายการ) โปรแกรมทำนาย **"ระดับฝีมือ" (Skill Tier)** ของนักยกน้ำหนักจากสถิติการยก

## ไฟล์ในชุดนี้
| ไฟล์ | หน้าที่ |
|---|---|
| `openpowerlifting.csv` | ข้อมูลดิบที่อัปโหลดมา (386,414 แถว) |
| `prepare_powerlifting_data.py` | สคริปต์ทำความสะอาด + แปลง `openpowerlifting.csv` เป็น `data.csv` |
| `data.csv` | ข้อมูลฝึกฝนที่พร้อมใช้ 1,500 แถว, 6 features + label (TIER) |
| `knn_app.py` | โปรแกรม GUI หลัก (Tkinter + scikit-learn kNN) — **รันไฟล์นี้** |
| `test_app.py` | สคริปต์ทดสอบความถูกต้องของข้อมูล/โมเดล |

## โจทย์ของโปรแกรมนี้: ทำนายระดับฝีมือจากสถิติการยก
ข้อมูลดิบ OpenPowerlifting ไม่มีคอลัมน์ "ระดับฝีมือ" ให้ตรงๆ จึงคำนวณ label ขึ้นจาก **Wilks Score**
(คะแนนมาตรฐานที่วงการยกน้ำหนักใช้เทียบฟอร์มข้ามน้ำหนักตัว/เพศ) โดยใช้เกณฑ์ที่นิยมใช้กันทั่วไป:

| Wilks Score | ระดับ (TIER) |
|---|---|
| < 200 | Beginner |
| 200–300 | Novice |
| 300–400 | Intermediate |
| 400–500 | Advanced |
| ≥ 500 | Elite |

** Wilks score **ไม่ได้ใช้เป็น feature** ในการเทรนโมเดล เพราะ label
ถูกคำนวณมาจากมันโดยตรง — ถ้าใส่ Wilks เป็น feature ด้วย โมเดลจะ "โกง" ได้คำตอบง่ายเกินไปโดยไม่ได้เรียนรู้
ความสัมพันธ์จริงจากข้อมูลการยก (feature leakage) โมเดลนี้เรียนรู้จาก **6 features จริง** ที่ไม่เกี่ยวกับ
Wilks โดยตรง: SEX, AGE, BODYWEIGHT, SQUAT, BENCH, DEADLIFT

## การทำความสะอาด/สุ่มข้อมูล (อยู่ใน `prepare_powerlifting_data.py`)
1. ตัดแถวที่ข้อมูลขาดหาย (Sex, Age, Bodyweight, Squat, Bench, Deadlift, Wilks)
2. ตัดแถวที่ค่ายกเป็นลบ (หมายถึงยกไม่สำเร็จ) หรืออายุ/น้ำหนักตัวผิดปกติ
3. เหลือข้อมูลสะอาด 106,615 แถว จากทั้งหมด 386,414 แถว
4. สุ่มแบบ **stratified** (แบ่งชั้นตาม TIER) คลาสละ 300 แถว รวม 1,500 แถว เพื่อให้
   - ข้อมูลแต่ละคลาสสมดุลกัน (ไม่เอนเอียงไปคลาสใดคลาสหนึ่ง)
   - จำนวนแถวพอเหมาะกับการแสดงผลใน GUI (ถ้าใช้ทั้ง 106,615 แถว ตารางจะโหลดช้ามาก)
   - ยังคงเป็น **ข้อมูลจริงทุกแถว** ไม่ได้ปั้นขึ้นมาเอง


## อย่าลืมใส่การอ้างอิงแหล่งที่มา
ในรายงาน/สไลด์นำเสนอ ให้ใส่ลิงก์หน้า Kaggle/แหล่งที่มาของไฟล์ `openpowerlifting.csv` ที่ใช้ (ข้อมูลนี้เป็น
ชุดข้อมูลโอเพนซอร์สจาก OpenPowerlifting.org ที่มีเผยแพร่บน Kaggle ด้วย) — เกณฑ์ข้อ 3 "คุณภาพของ Dataset"
ระดับดีเด่นต้องมีการอ้างอิงแหล่งที่มาชัดเจน

## จุดที่ตรงกับเกณฑ์การให้คะแนน
1. **นำเข้าข้อมูลเพื่อทำนาย** — ผู้ใช้กรอกครบ 6 features (SEX, AGE, BODYWEIGHT, SQUAT, BENCH, DEADLIFT)
   พร้อมตรวจสอบว่าเป็นตัวเลขและอยู่ในช่วงที่สมเหตุสมผล (`validate_inputs`)
2. **ปุ่มทำนาย + แสดงข้อมูลฝึกฝน** — ตาราง Treeview แสดงข้อมูลจริง 1,500 แถว พร้อมช่องค้นหาตาม TIER
3. **คุณภาพของ Dataset** — ข้อมูลจริงจาก OpenPowerlifting **มากกว่า 5 features (6 ตัว)**, 1,500 แถว
   (มากกว่า 500 ชัดเจน) — **อย่าลืมใส่ลิงก์อ้างอิงในรายงาน** เพื่อเกณฑ์ระดับดีเด่น
4. **เทคนิค kNN** — ใช้ `KNeighborsClassifier` จาก scikit-learn ผู้ใช้กรอกค่า k ได้อิสระผ่าน Spinbox (1-25)
5. **การออกแบบหน้าจอ** — จัดวางเลียนแบบภาพตัวอย่าง (โทนม่วง/เขียว, ตารางซ้าย, ฟอร์มกรอกขวา, ปุ่มทำนายล่าง)
6. **การตรวจสอบ/แก้ไขโปรแกรม** — `test_app.py` ทดสอบว่าโหลดข้อมูลถูกต้อง, โมเดลแม่นยำ 84-87% ในหลายค่า k,
   และทำนายกรณีตัวอย่างได้ถูกต้อง (มือใหม่ยกน้ำหนักน้อย → ถูกจัดเป็น Beginner/Novice)

## สิ่งที่ควรทำต่อ (สำหรับงานกลุ่ม 4 คน)
- แบ่งงาน: 1) เตรียมข้อมูล (ทำความสะอาด/เกณฑ์ Wilks), 2) ปรับแต่ง UI, 3) ปรับ logic kNN + ทดสอบ, 4) เตรียมนำเสนอ
- ลองปรับค่า k หลายๆ ค่าแล้วดูว่าผลทำนายเปลี่ยนไหม จะได้อธิบายตอนนำเสนอได้
- เตรียมอธิบายเรื่อง feature leakage (ทำไมไม่ใช้ Wilks เป็น feature) ให้ชัดเจน อาจารย์ถามตอบได้เลย
