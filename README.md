## 1. โจทย์และแนวคิดของโปรแกรม

โปรแกรมนี้ใช้เทคนิค **k-Nearest Neighbor (kNN)** ในการ**ทำนายระดับฝีมือ (Skill Tier)** ของนักกีฬายกน้ำหนัก
(powerlifting) จากสถิติการแข่งขัน โดยแบ่งระดับฝีมือออกเป็น 5 ระดับ ได้แก่ **Beginner, Novice, Intermediate,
Advanced, Elite**

แนวคิด: เมื่อผู้ใช้กรอกข้อมูลนักกีฬา (เพศ, อายุ, น้ำหนักตัว, สถิติท่า Squat/Bench/Deadlift ที่ดีที่สุด) โปรแกรม
จะเปรียบเทียบกับข้อมูลนักกีฬาจริงที่ใกล้เคียงที่สุด (เพื่อนบ้าน k คน) แล้วทำนายว่าน่าจะอยู่ในระดับฝีมือใด

## 2. ที่มาของชุดข้อมูล (Dataset)

| รายการ | รายละเอียด |
|---|---|
| แหล่งที่มา | OpenPowerlifting (เผยแพร่บน Kaggle) |
| ลิงก์อ้างอิง | https://www.kaggle.com/datasets/dansbecker/powerlifting-database |
| จำนวนข้อมูลดิบ | 386,414 แถว |
| จำนวนข้อมูลหลังทำความสะอาด | 106,615 แถว |
| จำนวนข้อมูลที่ใช้ฝึกฝนจริง | **1,500 แถว** (สุ่มแบบสมดุล 300 แถวต่อระดับ จาก 5 ระดับ) |

**ขั้นตอนการเตรียมข้อมูล** (ทำโดย `prepare_powerlifting_data.py`):
1. ตัดแถวที่ข้อมูลขาดหาย (เพศ, อายุ, น้ำหนักตัว, สถิติ Squat/Bench/Deadlift, Wilks Score)
2. ตัดแถวที่ค่าการยกเป็นลบ (หมายถึงยกไม่สำเร็จ) หรือมีอายุ/น้ำหนักตัวผิดปกติ
3. สุ่มตัวอย่างแบบ **stratified sampling** (แบ่งชั้นตามระดับฝีมือ) ระดับละ 300 แถว รวม 1,500 แถว
   เพื่อให้ข้อมูลแต่ละระดับมีจำนวนสมดุลกัน และขนาดพอเหมาะกับการแสดงผลในโปรแกรม

## 3. Features และ Label ที่ใช้

โปรแกรมใช้ **6 features**:

| Feature | ความหมาย | หน่วย |
|---|---|---|
| SEX | เพศ (1 = ชาย, 0 = หญิง) | - |
| AGE | อายุ | ปี |
| BODYWEIGHT | น้ำหนักตัว | กก. |
| SQUAT | สถิติท่า Squat ที่ดีที่สุด | กก. |
| BENCH | สถิติท่า Bench Press ที่ดีที่สุด | กก. |
| DEADLIFT | สถิติท่า Deadlift ที่ดีที่สุด | กก. |

**Label (สิ่งที่ทำนาย):** TIER — ระดับฝีมือ 5 ระดับ คำนวณจาก **Wilks Score** (คะแนนมาตรฐานที่วงการยกน้ำหนัก
ใช้เปรียบเทียบฟอร์มนักกีฬาข้ามน้ำหนักตัว/เพศ) ตามเกณฑ์ที่นิยมใช้กันทั่วไป:

| Wilks Score | ระดับ (TIER) |
|---|---|
| < 200 | Beginner |
| 200–300 | Novice |
| 300–400 | Intermediate |
| 400–500 | Advanced |
| ≥ 500 | Elite |

> **หมายเหตุสำคัญ:** Wilks Score **ไม่ได้ถูกใช้เป็น feature** ในการเทรนโมเดล เนื่องจาก label ถูกคำนวณมาจาก
> ค่านี้โดยตรง หากนำมาใช้เป็น feature ด้วยจะทำให้โมเดล "เห็นคำตอบ" ล่วงหน้า (feature leakage) ซึ่งไม่ใช่
> การเรียนรู้จากข้อมูลจริง โมเดลนี้จึงเรียนรู้จาก 6 features ที่ไม่เกี่ยวข้องกับ Wilks โดยตรงเท่านั้น

## 4. เทคนิคที่ใช้: k-Nearest Neighbor (kNN)

- ใช้ไลบรารี `scikit-learn` (`KNeighborsClassifier`)
- ก่อนเทรน ข้อมูลผ่านการทำ **Feature Scaling** (`StandardScaler`) เพื่อให้ทุก feature มีมาตราส่วนเท่ากัน
  (ป้องกันไม่ให้ feature ที่มีค่ามาก เช่น น้ำหนักยก มีอิทธิพลเกินจริงเมื่อเทียบกับ feature ที่มีค่าน้อย เช่น เพศ)
- ผู้ใช้สามารถ**เลือกจำนวนเพื่อนบ้าน (k) ได้อย่างอิสระ** ผ่านช่อง Spinbox (เลือกได้ตั้งแต่ 1 ถึง 25)
- เมื่อกดปุ่ม Predict โปรแกรมจะเทรนโมเดลใหม่ด้วยค่า k ที่เลือก แล้วทำนายผลทันที

## 5. ส่วนประกอบของโปรแกรม (GUI)

พัฒนาด้วย Python และไลบรารี **Tkinter** ประกอบด้วย

| ส่วน | รายละเอียด |
|---|---|
| ตารางแสดงข้อมูลฝึกฝน | แสดงข้อมูลจริง 1,500 แถว พร้อมช่องค้นหาตามระดับฝีมือ (TIER) |
| ฟอร์มนำเข้าข้อมูล (Input) | กรอกได้ครบทั้ง 6 features พร้อมตรวจสอบความถูกต้องของข้อมูล เช่น ต้องเป็นตัวเลข และอยู่ในช่วงที่สมเหตุสมผล |
| ตัวเลือกจำนวนเพื่อนบ้าน (k) | Spinbox เลือกค่า k ได้อิสระ 1–25 |
| ปุ่ม Predict | ทำนายระดับฝีมือและแสดงผลลัพธ์ทันที |

## 6. ผลการทดสอบความแม่นยำของโมเดล

ทดสอบด้วยการแบ่งข้อมูล 80% สำหรับเทรน และ 20% สำหรับทดสอบ (`test_app.py`) ได้ผลดังนี้:

| ค่า k | ความแม่นยำ (Accuracy) |
|---|---|
| 1 | 83.7% |
| 3 | 86.0% |
| 5 | 87.0% |
| 7 | 85.0% |

นอกจากนี้ยังทดสอบกรณีตัวอย่าง (unit test) เช่น นักกีฬาที่น้ำหนักตัวมากแต่ยกน้ำหนักได้น้อย โปรแกรมทำนาย
ผลถูกต้องว่าอยู่ในระดับ Beginner/Novice ตามที่คาดไว้
